StatelessWidget : widget sans état modifiable. Exemple : AppBar.
StatefulWidget : widget avec état modifiable. Exemple : AnimePage avec le compteur vus.

2 - Sans setState, le compteur change en mémoire, mais l'écran ne se met pas à jour automatiquement.

3 - 
Commit : enregistre les modifications dans Git localement.
Sync Changes : synchronise les commits avec le dépôt distant (GitHub).
